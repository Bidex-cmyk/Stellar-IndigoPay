# 🎥 Demo Video Recording Script

**Duration:** ~2 minutes | **Tool:** Loom, Screen Studio, or OBS

## Flow

### 1. Open the Live App (0:00–0:10)
- Navigate to `https://stellar-indigo-pay.vercel.app`
- Show the homepage with project cards and impact stats
- Mention: "Stellar-IndigoPay is a climate donation platform on Stellar Testnet"

### 2. Wallet Connection (0:10–0:30)
- Scroll to the wallet connect card
- Show the multi-wallet picker with Freighter, Albedo, xBull, Rabet options
- Click "Freighter" 
- Approve the connection in the Freighter extension popup
- **Highlight:** "Multiple Stellar wallets supported — pick any"

### 3. View Balance (0:30–0:40)
- Navigate to the Dashboard
- Point out the XLM balance display
- Mention: "Your balance auto-refreshes after every donation"

### 4. Browse Projects (0:40–0:55)
- Go back to the homepage
- Browse through project cards
- Click on "Amazon Reforestation" (or any project)
- Show the project detail page with CO₂ impact, milestones, and ratings

### 5. Make a Donation (0:55–1:20)
- Enter an amount (e.g., 10 XLM)
- Optionally add a message
- Click "Donate"
- Approve the transaction in Freighter
- Show the "Building → Signing → Submitting → Recording" flow
- Show the success card with updated balance and Stellar Expert link

### 6. Verify on Stellar Explorer (1:20–1:35)
- Click "View on Stellar Expert"
- Show the transaction on the Stellar Testnet explorer
- Point out: contract ID, transaction hash, verifiable on-chain

### 7. Mobile Responsive (1:35–1:50)
- Open Chrome DevTools → Toggle Device Toolbar → iPhone 12 Pro
- Show the homepage adapting to mobile layout
- Show the wallet connect flow on mobile

### 8. CI/CD & Wrap-up (1:50–2:00)
- Switch to GitHub Actions tab
- Show the passing CI pipeline
- Mention the deployed contract address
- Close with: "Production-ready, open-source, and verifiable on-chain"
